# 73rd Street Associates Corporate Website

Official corporate website for 73rd Street Associates, Inc. - A Meta Platform Tech Provider specializing in Facebook and Instagram integration services.

## Overview

This website serves as the primary digital presence for 73rd Street Associates, Inc., showcasing our technology services, Meta Platform integration expertise, and compliance documentation.

## Tech Stack

- **Framework:** Next.js 15 with App Router
- **Language:** TypeScript
- **Styling:** Tailwind CSS 4
- **Deployment:** Ready for Vercel or similar platforms

## Features

### Pages
- **Homepage** - Company overview and key services
- **About** - Company history and leadership
- **Services** - Detailed service offerings
- **Meta Platform** - Tech Provider designation and permissions
- **Privacy Policy** - Comprehensive privacy practices
- **Data Deletion** - Clear data deletion instructions
- **Terms of Service** - Service terms and conditions
- **Code of Conduct** - Community guidelines
- **Contact** - Contact form and information

### Key Features
- Responsive design for all devices
- SEO optimized with metadata
- Accessibility compliant
- Professional corporate design
- Meta Platform compliance documentation
- Secure contact form

## Getting Started

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## Development

The development server runs on `http://localhost:3000` by default.
